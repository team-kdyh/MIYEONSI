# 💬 말빨 시뮬레이터

현실에서 마주칠 수 있는 상황(교수님 면담, 부장님께 연차 요청 등)을 **대화로 뚫는 연습 게임**입니다.
선택지를 고르거나 직접 말을 입력하면, 상대방의 **호감도 · 신뢰도 · 인내심**이 변하고,
끝나면 "어떤 말이 왜 먹혔는지" 리뷰를 보여 줍니다.

## 실행 방법
`index.html`을 더블클릭하면 브라우저에서 바로 실행됩니다. 설치할 것은 없습니다.

## 파일 구조
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 틀, 스크립트 불러오기 |
| `style.css` | 디자인 |
| `game.js` | 게임 엔진: 화면 흐름, 수치 계산, 난이도 규칙, 판정(규칙/AI), 리뷰 화면 |
| `scenarios/professor.js` | 상황 1: 교수님께 연구실 컨택하기 |
| `scenarios/boss.js` | 상황 2: 부장님께 연차 요청하기 |
| `scenarios/interview.js` | 상황 3: 대학교 면접 보기 |
| `scenarios/vendor.js` | 상황 4: 거래처의 단가 인하 요구 막아내기 (나 = 납품업체) |
| `scenarios/landlord.js` | 상황 5: 집주인에게 수리 요청하기 (나 = 세입자) |
| `scenarios/parttime.js` | 상황 6: 알바 사장님께 못 받은 돈 요청하기 (나 = 알바생) |
| `scenarios/customer.js` | 상황 7: 화난 손님 응대하기 (나 = 직원) |

### 상황별로 연습되는 것
| 상황 | 상대 (하 / 중 / 상) | 핵심 기술 | 돌발 상황 예 |
|---|---|---|---|
| 🏫 대학교 면접 | 따뜻한 입학사정관 / 꼼꼼한 전공 교수 / 압박 면접관 | 경험을 구체적으로, 모르는 건 솔직하게, 약점 → 성장 | 모르는 전공 질문, 말 끊기, 서류 착각, 가치관 질문, 머리가 하얘짐 |
| 🤝 거래처 단가 협상 | 합리적인 과장 / 숫자만 보는 차장 / 갑질 상무 | 양보엔 대가 붙이기, 마지노선 지키기, 문서화 | 경쟁사 견적, 반말·무시, 납기 당기기, 접대 요구, 우리 팀장의 "다 들어 줘" |
| 🏠 집주인 수리 요청 | 인심 좋은 할머니 / 바쁜 직장인 / 버티는 건물주 | 증거로 말하기, 비용 원칙 + 수고는 양보, 의제 분리 | 아랫집 누수, "네가 고쳐", "계약서에 없다", 전화 끊김 |
| 🧾 알바 사장님 | 다정한 사장님 / 계산 빠른 사장님 / 버럭 사장님 | 기록으로 증명, 공감하되 권리는 지키기, 보복 암시 대응 | 손님 몰림, 가게 적자, 다른 알바와 비교, 계약서 미작성 |
| ☕ 화난 손님 | 속상한 손님 / 따지는 손님 / 소리 지르는 손님 | 감정 먼저 받기, 할 수 있는 것부터, 인격 모독엔 선 긋기 | 인격 모독, 뒤에 줄, "사장 나와", 알고 보니 내 실수, 촬영 |

## 난이도 = 상대방 성격
| 난이도 | 예시 | 규칙 (`game.js`의 `LEVEL_RULES`) |
|---|---|---|
| 하 | 친절한 교수님 / 온화한 부장님 | 좋은 말 효과 ×1.2, 나쁜 말 ×0.6, 수치 공개 |
| 중 | 바쁜 교수님 / 깐깐한 부장님 | 기본 배율, 인내심이 더 빨리 줄어듦 |
| 상 | 깐깐한 교수님 / 버럭 부장님 | 나쁜 말 ×1.5, 인내심 급감, **수치 숨김** |

같은 질문이라도 난이도마다 상대의 **대사와 반응이 다르게** 쓰여 있습니다 (`{ 하: "...", 중: "...", 상: "..." }`).

## 👥 3명이서 이어서 만드는 방법 (직렬 분담)

앞사람이 만든 것 위에 다음 사람이 기능을 쌓는 방식입니다. 각 단계가 끝나면 **그 상태로도 게임이 돌아가야** 합니다.

### 1단계 — 뼈대 + 난이도 '하' (1번 사람)
- 화면 흐름: 상황 선택 → 난이도 선택 → 대화 → 결과
- 수치 3개(호감도/신뢰도/인내심)와 **선택지** 진행
- 시나리오 데이터 형식 확정 (`scenarios/*.js`)
- 상황 1개를 '하' 난이도로 완성
- ✅ 인계 조건: 선택지만으로 상황 1개를 처음부터 끝까지 플레이할 수 있음

### 2단계 — 난이도 '중' + 직접 입력 (2번 사람)
- '중' 대사/반응 추가, 난이도별 배율·인내심 감소 규칙(`LEVEL_RULES`)
- 인내심이 바닥나면 대화가 끊기는 **실패 엔딩**
- **직접 입력** + 키워드 규칙 판정 (`judgeWithRules`, 시나리오의 `free.good / free.bad`)
- 두 번째 상황 추가
- ✅ 인계 조건: 하/중 둘 다 플레이 가능, 직접 입력에 반응함

### 3단계 — 난이도 '상' + AI + 리뷰 (3번 사람)
- '상' 대사/반응 추가, '상'에서는 수치 숨기기
- **AI 판정**: OpenAI API가 상대역을 연기하고 점수·코칭을 줌 (`judgeWithAI`)
- **리뷰 화면**: 턴별 피드백, 가장 잘한 말/아쉬운 말, 이 상황의 핵심 교훈
- 점수 밸런스 조정 (상은 거의 완벽해야 통과)
- ✅ 완성: 모든 난이도, 선택지 + 직접 입력 + 리뷰

> 지금 이 폴더에는 3단계까지 모두 구현된 **완성 예시**가 들어 있습니다.
> 팀에서 처음부터 만들 땐 위 단계를 참고하고, 막히면 해당 부분 코드를 참고하세요.

## 🧠 "연습"이 되게 만드는 장치
- **직접 말하기가 기본**: 선택지는 막혔을 때 보는 힌트예요. 리뷰에 "힌트 봄"이 표시돼요.
- **정답이 상대마다 다름**: 같은 말도 친절한 교수님에겐 +, 바쁜 교수님에겐 −. 선택지 순서도 매번 섞여요.
- **분기 + 돌발 상황**: 논문을 언급하면 "그럼 한계는?" 꼬리 질문이 오고, 중간에 거절당하거나 계획이 꼬여요.
- **수치 숨김 (중·상)**: 숫자 대신 표정만 보여요. 속마음은 끝나고 리뷰에서 공개돼요.
- **제한 시간 (중·상)**: 머뭇거리면 침묵으로 처리돼서 감점돼요.
- **모범 답안**: 리뷰에서 "이 상대에게 더 통했을 말"을 보여 줘요.
- **⚡ 랜덤 돌발 상황**: 상황마다 돌발 상황이 5개씩 있고, 매 판 그중 1~3개(서로 다른 것)가 랜덤한 시점에 터져요.
  (교수님: 대학원생 난입, 전화, 시간 단축, 착각, 기습 질문 / 부장님: 동료도 휴가, 전화로 기분 급변, 동료와 연차 겹침, 상무님이 마감 당김, 착각)
- **상황 정보 입력**: 시작 전에 학과·연구 분야·읽은 논문·내 정보 등을 적으면 대사에 들어가요 (입력값은 브라우저에 저장됨).
- **상대 성격 직접 설정**: 하/중/상 대신 "내가 아는 사람으로"를 골라 실제 성격·말투·좋아하는 것·싫어하는 것을 적을 수 있어요.
- **AI 맞춤 진행**: AI 키가 있으면 입력한 정보와 성격에 맞춰 AI가 매 장면 대사·질문·선택지를 새로 써요.
  (키가 없으면 정해진 대사에 빈칸만 채워져요)
- **✏️ 나만의 상황**: 상황·상대·목표를 직접 적으면 AI가 대화를 처음부터 끝까지 진행해요 (AI 키 필요).

## ➕ 새 상황 추가하기
1. `scenarios/boss.js`를 복사해서 `scenarios/새상황.js`로 만들고 내용을 바꿉니다.
2. `index.html`에 `<script src="scenarios/새상황.js"></script>`를 추가합니다.

대화는 **노드(장면)** 로 이어집니다. `start`에서 시작해서 `next`를 따라가고, `"end"`면 끝납니다.

```js
nodes: {
  p1: {
    narr: "돌발 상황 설명 (선택)",
    npc: { 하: "상대 질문", 중: "...", 상: "..." },
    next: "p2",                                            // 기본 다음 장면
    choices: [
      { text: "내가 할 말",
        // 같은 말도 상대 성격마다 다르게 먹히게! (전부 같으면 { like: 5, trust: 5 } 처럼 한 번만)
        eff: { 하: { like: 10, trust: 4 }, 중: { like: 2, patience: -6 }, 상: { trust: -4 } },
        react: { 하: "반응", 중: "...", 상: "..." },
        fb: "리뷰 코칭 (난이도별로 다르게 써도 됨)",
        next: "p2tail",                                    // 이 말을 하면 꼬리 질문으로 분기 (선택)
        end: "fail" },                                     // 이 말을 하면 바로 끝남 (선택)
    ],
    free: {                                                 // 직접 입력
      hint: "입력창 안내", tip: "못 맞췄을 때 팁",
      rubric: "AI 판정 기준",
      good: [{ words: ["키워드"], stat: "trust", points: 8, note: "칭찬" }],
      bad:  [{ words: ["키워드"], stat: "like",  points: 8, note: "주의" }],
      routes: [{ when: "AI용 분기 조건", words: ["키워드"], next: "p2tail" }],
    },
  },
}
```

상황 정보 칸과 돌발 상황:
```js
setup: [  // 시작 전 입력 칸. var 가 있으면 대사 속 {학과} 같은 빈칸에 들어감
  { key: "major", var: "학과", label: "교수님 소속 학과", placeholder: "예: 전기공학과", default: "○○학과" },
],
events: {  // 매 판 1~3개가 랜덤으로 끼어듦. 끝나면 원래 흐름으로 돌아감
  phone: {
    minPos: 2,                                  // 이 시점 이후에만 등장 (선택)
    narr: "교수님 휴대폰이 울린다…",          // 무슨 일이 생겼는지. 착각 상황이면 실제로는 어떤지도 괄호로 적기
    after: "통화가 끝나고 다시 면담으로 돌아간다.", // 끝나고 원래 대화로 돌아갈 때 연결 문장 (선택)
    npc: {...}, choices: [...], free: {...},
  },
},
```
돌발 상황은 랜덤한 시점에 나오므로, "회의가 끝나 갈 무렵"이나 "단가 깎아 줬으니"처럼 **특정 시점이나 아직 안 나온 내용을 전제하는 문장은 쓰지 마세요.**
꼬리 질문처럼 바로 앞 대화와 이어져야 하는 장면에는 `tail: true`를 붙이면 그 직전엔 돌발 상황이 끼어들지 않아요.

**밸런스 팁**: 아무거나 눌렀을 때 성공 확률이 대략 하 50% · 중 20~25% · 상 5% 이하가 되도록 맞춰 뒀어요.
상황마다 점수 흐름이 다르면 시나리오에 `clear: { 하: 65, 중: 70, 상: 62 }`로 통과 기준을 따로 줄 수 있어요.

## 🤖 AI 판정 (선택)
오른쪽 위 **⚙️ AI 설정**에 OpenAI API 키를 넣으면 직접 입력한 말을 AI가 판정합니다.
- 키는 **그 브라우저에만** 저장됩니다. 코드나 파일에 키를 적지 마세요.
- **키를 깃허브, 카톡, 채팅에 올리지 마세요.** 노출되면 바로 폐기하세요.
- 키가 없으면 키워드 규칙으로 판정되니 키 없이도 게임은 돌아갑니다.
