# AFTER HOURS / 퇴근 후에

성인 인물들의 선택과 관계를 다루는 한국어 오리지널 비주얼 노벨입니다. 직장 미션 코미디 **칼퇴의 기술**, 로맨스 심리 스릴러 **너의 목소리를 빌려줘**를 같은 게임 셸에서 플레이합니다. 직장 모드는 8개 미션과 미션별 3종 결과, 로맨스는 6장과 4개 엔딩으로 구성됩니다.

## Windows 실행

**`play.cmd`를 더블클릭하면 실행됩니다.** 처음에는 의존성을 설치하고 게임을 빌드한 뒤 브라우저를 엽니다. Node.js 22 이상이 필요합니다. 게임 서버를 종료하려면 `stop.cmd`를 실행하세요. 저장 기록은 유지됩니다. 아래는 터미널로 직접 실행하는 방법입니다.

Node.js 22 이상과 npm이 필요합니다. PowerShell에서 이 README가 있는 프로젝트 폴더로 이동한 뒤 실행하세요. 경로에 공백이나 한글이 있으면 따옴표로 감싸세요.

```powershell
npm install
npm run typecheck
npm test
npm run build
npm start
```

브라우저에서 **http://127.0.0.1:3001** 을 엽니다. 서버 종료는 터미널에서 Ctrl+C입니다. 실행할 때마다 같은 주소와 브라우저를 사용하세요. 포트 3001을 다른 프로그램이 사용한다면 해당 프로그램을 종료한 뒤 다시 실행합니다.

개발 중에는 `npm run dev`로 서버와 Vite를 함께 실행하고 **http://127.0.0.1:5173** 에 접속합니다. 프로덕션 명령은 빌드된 `dist`를 Node 서버에서 제공합니다.

## 플레이

1. 타이틀에서 모드를 고르고 안내를 읽은 뒤 시작합니다. 새 게임은 현재 자동 저장을 교체합니다.
2. 제안 답변을 고르지 않고도 자유 문장을 쓰고 **대답하기**를 누르면 대화하고, 장면에서 인정되는 제안이나 결정을 표현하면 합의·관계·진행에 반영됩니다. 세 가지 제안 답변으로 선택을 전달할 수도 있습니다. 입력한 문장이 있으면 그 의미를 우선 판정하며, 선택 해제로 자유 대화에 돌아갈 수 있습니다.
3. 직장에서는 실제 시간·책임·권한 조건을 확보해야 합니다. 로맨스는 검증한 관계 사실과 단서, 마지막 선택으로 엔딩이 갈립니다. 자유 입력과 제안 답변 모두 서버 규칙으로 판정합니다.
4. **이어하기**는 자동 저장을 엽니다. **세이브**에는 수동 저장 3칸이 있습니다. 분기 직전에 저장해 다른 결말을 볼 수 있습니다.
5. **컬렉션**은 발견한 28개 엔딩을 보관합니다. 새 게임이나 불러오기로 발견 기록이 사라지지 않습니다. **대화 로그**에서 실제 작성한 대사를 다시 읽을 수 있습니다.
6. **설정**은 효과 감소, 음소거, 음량, 읽기 속도, 큰 글씨를 지원하고 브라우저에 유지됩니다. 원본 배경음과 효과음은 플레이 시작 후 재생됩니다. 효과 감소에서는 움직임과 타이핑을 정적으로 대체하며 사건 정보와 선택은 유지됩니다. Tab으로 이동하고 Enter로 대답하며 Escape로 창을 닫습니다. 설정의 처음부터 시작 버튼으로 재시작할 수 있습니다.

## 실행 범위와 저장

기본값은 **OFFLINE DEMO**입니다. 설정의 대화 제공자를 OpenAI로 바꾸면 서버가 공식 Responses API를 호출합니다. 루트 `.env` 또는 서버 환경변수에 `OPENAI_API_KEY`를 설정하세요. `OPENAI_MODEL`로 모델을 바꿀 수 있으며 기본값은 `gpt-4.1-mini`입니다. 실제 키는 브라우저, 소스, 로그에 넣지 않습니다. `.env`는 Git에서 제외됩니다. 실패 시 자동으로 오프라인 응답을 성공 처리하지 않습니다.

OpenAI 모드에서는 두 인물이 입력에 응답하는 한국어 대사를 최대 600자로 생성합니다. 구조·정본 참조 ID는 엄격한 JSON schema와 서버 재검증을 거치며, 생성 대사는 정본 사건으로 승격되지 않습니다. 자유 입력의 합의·관계·단서 변화는 미션/장별 서버 규칙으로 판정합니다. 규칙 밖 표현은 진전하지 않을 수 있으며, 제안 답변으로 명확한 선택을 전달할 수 있습니다. 생성 문장의 의미적 정확성은 스키마만으로 보장되지 않습니다.

현재 장면, 완료 선택, 합의 의도, 관계·경계, 확인한 단서는 출처 사건 ID·상태 버전·확정 시각이 있는 별도 정본에 보존됩니다. 사용자 주장, 모델 대사, 인물 추측은 정본과 구분합니다. 최근 대화는 12항목, 비정본 이력은 24항목까지이며 API에는 정본을 별도로 전달합니다.

입력은 최대 500자, 본문 최대 4KB, 브라우저 프로필당 시간당 변경 요청 300회입니다. 플레이당 대화 시도 100회 한도는 실패를 포함해 디스크에 보존합니다. 동시 요청은 거부하며 서버는 10초, 브라우저는 12초에 취소합니다. 화면의 응답 취소, 같은 요청 다시 시도, 상태 다시 확인을 사용할 수 있습니다. 성공 턴과 요청 ID를 원자적으로 저장해 동일 요청 재시도는 같은 결과를 반환합니다. 변경된 입력이나 오래된 상태 버전은 거부합니다.

실제 API 검증은 누적 12회 실행했습니다(요청당 출력 상한 700토큰). 최종 4회에서는 자연스러운 자유 입력 두 번으로 칼퇴 성공 엔딩에 도달했고, 유나가 플레이어의 빗소리·귤 취향과 자신의 시나몬 향 취향을 명시적으로 구분해 회상했습니다. 실제 원문·상태·당시 코드 해시는 `docs/final-live-evidence.json`, 검증 범위는 `docs/final-verification.md`에 있습니다. 모든 대화나 엔딩을 실제 API로 검증한 것은 아닙니다. 일반 자동 테스트는 유료 호출을 하지 않습니다.

저장 데이터는 Git에서 제외되는 `.local-data`에 저장되고 HttpOnly 쿠키로 연결됩니다. 서버를 재시작해도 보존됩니다. 쿠키를 지우면 기존 기록에 접근할 수 없고, 이 폴더를 지우면 모든 로컬 저장이 삭제됩니다. 다른 PC로 옮기는 기능은 없습니다. 로컬 파일을 직접 편집할 수 있는 운영체제 사용자를 방어하는 보안 저장소는 아닙니다.

저장 형식이 맞지 않거나 파일이 손상되면 마지막 유효 백업으로 복구하고 안내합니다. 백업도 복구할 수 없으면 진행을 차단하며, 화면에서 확인 후 저장을 초기화할 수 있습니다(모든 슬롯과 해금 삭제). 연결이 끊기면 화면의 **같은 요청 다시 시도** 또는 **상태 다시 확인**을 사용하세요. 이미 처리한 선택 이후 진행이 바뀌었다면 현재 상태를 복구하며 과거 선택을 다시 적용하지 않습니다. 현재 저장·복구 검증은 `docs/ac6-validation.md`에 기록했습니다.

## 에셋과 검증

`THIRD_PARTY_NOTICES.txt`에 설치된 실행 의존성 68개의 라이선스 원문을 보관합니다. 의존성을 바꾼 뒤 `node scripts/generate-notices.mjs`로 갱신할 수 있습니다.

`public/assets/generation-manifest.json`에 부모 실행에서 생성한 원본 PNG의 출처·프롬프트·권리 참고가 있습니다. PNG 원본은 수정하지 않습니다. CSS로 4표정 스프라이트를 잘라 사용합니다. 글꼴은 시스템 한국어 sans-serif를 사용하므로 실행 시 외부 폰트 연결이 필요하지 않습니다.

`npm test`는 미션 합의, 729개 로맨스 선택 조합, 정본 검증, 실제 서버의 저장·재시작·오류 복구를 검사합니다. 브라우저 테스트는 24개 직장 결말과 4개 로맨스 엔딩을 공개 API로 도달하고, 대표 두 모드를 화면 조작으로 완주합니다. 현재 증거의 기준 문서는 `docs/QA.md`입니다. 과거 AC 문서는 당시 구현에 대한 기록입니다.

브라우저 통합 검증은 `npx playwright install chromium`을 최초 한 번 실행한 뒤 `npx playwright test`로 재현합니다. 프로덕션 빌드가 먼저 필요하며 테스트가 로컬 서버를 자동 실행합니다.

Windows 설치·빌드와 두 모드 공통 화면의 최신 검증은 `docs/ac1-validation.md`에 있습니다. 저장 데이터를 분리한 공통 화면 검사만 실행하려면 빌드 후 `npx playwright test --config playwright.ac1-final.config.ts`를 사용하세요.

연출 매핑·접근성·1440×900 및 390×844 화면 검증은 `docs/ac5-validation.md`, 실행 관찰과 소스 해시는 `docs/ac5-evidence.json`에 있습니다.
