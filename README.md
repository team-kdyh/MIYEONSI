# AFTER HOURS / 퇴근 후에 — v2 로컬 후보

선택지 없이 자유 문장으로 대화하는 한국어 비주얼 노벨입니다. 부장님 편에는 8개 직장 협상이 있고, 서유나 편에서는 소리 수집가와의 로맨스·심리 스릴러를 진행합니다.

## 부장님 편

**칼퇴의 기술**에서 일반 협상 또는 3분 타임어택을 선택하세요. 박도현·윤서진 부장 중 한 명과 상대 성격을 고르고, 내 프로필에서 직장·직무·성별을 설정할 수 있습니다. 성별은 선택 사항입니다.

자유롭게 묻거나 제안하면 부장이 대답합니다. 실제 제안이 통하면 부장 버티기가 줄고, 부장이 압박을 밀어붙이면 내 여유가 줄어듭니다. 제한 시간 안에 부장 버티기를 0으로 만들면 승리합니다. 일반 협상은 시간제한이 없습니다. 타임어택은 답변 대기나 메뉴에서도 시간이 흐르며, 서버가 마감 전에 받은 대사는 판정까지 마칩니다. 저장을 불러와도 원래 마감 시각을 적용합니다.

지난 발언은 무대 채팅창이나 대화 로그에서 읽을 수 있습니다. 결말의 **협상 리포트 보기**에서 결과, 소요 시간, 가장 효과가 컸던 발언, 압박을 받은 대화와 교환별 피드백을 확인할 수 있습니다.

상대 성격·회사 설정과 발언별 리뷰는 ysb028의 [말빨 시뮬레이터](https://github.com/team-kdyh/MIYEONSI/tree/9ef505ed96d94e180b35b27b82ac54df14372be4)에서, 무대·포즈·자유 대화 판정과 저장은 [AFTER HOURS](https://github.com/team-kdyh/MIYEONSI/tree/fd91bd9183ad7f29460685a1ecaad737b38a0498)에서 이어 왔습니다.

## Windows 실행

Node.js 22 이상을 설치하고 **play.cmd**를 더블클릭하세요. 의존성을 설치하고 빌드한 뒤 브라우저가 열립니다. **stop.cmd**는 이 프로젝트가 시작한 서버만 종료하며 저장을 지우지 않습니다. 기본 주소는 http://127.0.0.1:3001 입니다. 해당 포트가 이미 사용 중이면 PowerShell에서 `$env:AFTERHOURS_PORT='3057'`을 설정한 뒤 `./play.cmd`를 실행할 수 있습니다.

직접 실행:

```powershell
npm ci
npm run build
npm start
```

개발 실행은 `npm run dev`이며 http://127.0.0.1:5173 에 접속합니다. 서버만 별도 포트로 시작할 때는 `PORT` 환경변수를 사용하세요.

## OpenAI 설정과 플레이

`.env.example`을 `.env`로 복사해 본인의 `OPENAI_API_KEY`를 서버에 설정하세요. 키가 있으면 새/기존 브라우저의 기본 제공자는 OpenAI입니다. 직접 선택한 제공자는 유지됩니다. 기본 모델은 **gpt-4.1**, `OPENAI_MODEL`로 변경 가능합니다. 기존 `.env`에 `gpt-4.1-mini`가 설정돼 있으면 그 설정이 우선하므로 확인하세요. 키를 브라우저·대화·소스·배포 파일에 넣지 마세요.

1. 모드와 직장 미션을 고르고 이야기 시작을 누릅니다. 자유 문장을 입력하고 전송합니다. 이야기 답변 버튼은 없습니다.
2. 인물은 농담, 취향, 새 업무 대안, 약속과 거절에 응답합니다. 합의와 관계·장소 변화는 실제 입력과 검증된 사건을 바탕으로 저장됩니다. 단순 대사에 나온 사실이 모두 확정 상태가 되는 것은 아닙니다.
3. 세이브에는 수동 3슬롯이 있고 자동 저장은 계속 유지됩니다. 대화 로그·설정·컬렉션은 메뉴에서 엽니다. 미발견 결말은 미리 공개하지 않습니다.
4. 설정에서 음량·음소거·효과 감소·큰 글씨·읽기 속도를 바꿉니다. Tab으로 이동하고 Enter로 전송합니다. 배경음은 사용자 조작 후 재생됩니다.
5. 키가 없거나 직접 선택한 **오프라인 연출 체험**은 화면·음악 미리보기입니다. 실제 AI 이야기 진행을 대신하지 않습니다. AI 실패를 자동 오프라인 성공으로 바꾸지 않습니다.

현재 장·장소와 상황을 화면 위쪽에서 확인합니다. 합의 개수와 해야 할 일 체크리스트는 표시하지 않습니다. 일반 대화는 새 합의 없이도 이어지며, 실제 사건 기록이 필요한 경우에만 상태 변경을 제안합니다. 질문·농담·거절·화제 전환을 받아들이고, 인물에게 방법을 물으면 말로 제안하도록 지시했습니다. 대사 창은 답변 길이에 맞춰 늘어나고 화면에 다 담기지 않는 긴 내용만 ‘계속 읽기’로 넘깁니다.

검증에 실패한 AI 초안은 원래 입력과 이전 상태를 그대로 둔 채 최대 한 번 자동 재작성합니다. 수정된 전체 대사와 사건이 검증되면 한 턴으로 저장합니다. 정상 대화는 모델 호출 1회, 자동 재작성까지 필요하면 최대 2회이며 각각 1600토큰 상한과 게임당 100회 시도 한도에 포함됩니다. 전체 처리 제한은 30초입니다. 저장/연결 실패나 제공자의 명시적 거절은 자동 재작성하지 않습니다. 끝내 답변을 받지 못해도 입력을 고치도록 요구하지 않으며, ‘답변 다시 받기’ 또는 전달이 불명확한 경우 ‘이어받기’로 원래 말을 재시도할 수 있습니다.

페이지 열기/새로고침은 모델을 호출하지 않습니다. 입력은 1–500자, 요청 본문은 4KB 이하입니다. Responses 출력 상한은 1600토큰입니다. 서버 응답 제한은 30초이며 취소·재시도·현재 상태 복구를 지원합니다. 동일 요청 ID는 중복 진행을 만들지 않습니다. 프로필당 시간당 변경 요청 300회, 게임당 요청 시도 100회 제한은 실패도 포함합니다.

## 저장과 개인정보

기본 저장은 Git에서 제외된 `.local-data`와 HttpOnly 브라우저 쿠키에 연결됩니다. 서버 재시작과 구버전 저장을 지원하며 개인 저장은 배포 ZIP에 포함하지 않습니다. 쿠키를 지우면 해당 기록에 접근할 수 없습니다. 손상된 저장은 백업 복구를 시도하고, 복구 불가능할 때만 확인을 거쳐 초기화합니다. 운영체제 파일을 편집할 수 있는 사용자를 방어하는 보안 금고는 아닙니다.

OpenAI 모드에서는 플레이어의 입력, 인물 정보, 최근 대화, 확정 사건과 오래된 플레이어 발화가 API에 전달됩니다(`store:false`). 오래된 발화는 녹음 거절 같은 약속을 잊지 않도록 게임당 최대 100개까지 유지합니다. 모델 대사와 사용자 주장은 확정 사건과 구분됩니다. 게임은 실제 바탕화면이나 사생활을 읽지 않습니다.

## 검증과 알려진 한계

게이지를 도입한 버전의 결과는 [부장님 설득 배틀 검토](docs/battle-review/README.md)에 기록합니다. 100/100 게이지, 새 논거의 연계, 압박에 대한 방어·반격, 게이지 소진 승패와 재도전을 추가했습니다. 같은 주장의 반복은 피해를 쌓지 않으며 질문·농담은 자유롭게 이어갑니다. 직장 배틀의 합의는 별도 기록하고 게이지 승리를 합의 체크리스트에 묶지 않습니다. 로맨스의 약속·참여 검증은 유지합니다. 추가24회 실제 API 시도를 모두 기록했고 실패4턴도 보존했습니다. 실제 한 판의 승리는 확인했지만 마지막 난도 지시 보완은 새 모델 생성으로 재검증하지 않았습니다. 사람의 밸런스 평가와 다양한 실제 패배·방어 경로 검증이 남아 있습니다. 상용 출시 승인이나 공식 Ralph 통과를 뜻하지 않습니다.

이전 수정은 [자유 대화와 내부 재작성 검토](docs/flexible-review/README.md)에 기록합니다. nullable 사건 기록, 같은 입력으로 재작성, 호출 시도 계상과 중복 방지, 현재 상황 표시를 검사했습니다. 실제 모델을 새로 호출해 장기 대화 품질이나 오류 빈도를 확인한 결과는 아닙니다. 아래 읽기 UI 및 이전 Ralph 보고서는 각 버전의 역사로 보존합니다.

최신 화면·복구·진행 안내 수정은 [읽기와 진행 안내 검증](docs/reading-review/README.md)에 따로 기록합니다. 아래388/28 및 Ralph 기록은 직전 소스의 결과입니다. 이번 요청은 일시정지한 전체 목표를 재개하지 않는 개별 수정이며 추가 유료 API 호출은 하지 않았습니다. AI 지시를 보완했지만 실제 모델의 오류 빈도 감소나 장기 이야기 품질을 새로 검증했다는 뜻은 아닙니다.

최근 통합본은 공동 약속·부분 이행·위임과 조건 변경에 더해 변경 제안·거절·철회·적용 실패 이력을 구분해 저장합니다. 변경을 거절해도 원래 약속은 남으며, 조건별 이행 근거와 수행 해석 진단을 별도로 보존합니다. 앞 문장만 인용해 뒤의 철회를 무시하던 오류와 무관한 커피 거절이 변경을 막던 오류도 수정했습니다. 앞선 음악·소품 그림·Windows 실행 수정은 유지했습니다. 동일 소스의 격리본에서 빌드·단위388개·브라우저28개가 통과했고 실제 서버를 다시 실행했습니다. [최신 후보와 검증 범위](docs/v2-g3-parent-integration/README.md)를 참고하세요. 해석은 제한된 한국어 문법이며 일반적인 문장 의미 이해를 보장하지 않습니다. 최신 실제 모델 검증과 음악 청취 평가가 남아 출시 승인은 보류합니다.

앞선 통합본의 빌드·단위358개·브라우저25개 결과와 공식 Ralph0/7·QA0.52/REVISE 판정은 [이전 검증 범위](docs/v2-state-parent-integrated/review.md)에 보존합니다. 후속 Ralph의 조건 변경1·2·3세대도 모두0/7로 거절됐으며3세대에서 개선 정체로 종료됐습니다. 평가자의 원자료 직접 접근 한계와 실제 모델·청취 미검증을 별도로 기록했습니다. [공식 원문과 종료 기록](docs/v2-revision-ralph/parent-index.md)을 보존하며, 부모의 자동검사 통과를 공식 출시 등급으로 대신하지 않습니다. 아래325개 이전 기록과302/25 검사도 각각 당시 소스의 역사이며 최신 실제 모델 검증을 뜻하지 않습니다.

직전 통합 보완본은 타입 검사·빌드, 단위 검사302개와 브라우저 검사25개를 통과했습니다. 이전 약속 진단4건과 새로 재현한 미래 이동·데이트 연기·거절 처리 오류를 수정했고 진단은5/5입니다. 그 시점의 소스·실행·실패 보존 범위는 [통합 보완본 검토](docs/v2-parent-final/review.md)에 있습니다. 실제 모델 재검증이 남아 출시 승인은 보류합니다. 이전211개/244개 검사, Ralph3/7 및 순차1세대0/7 공식 판정도 원문 그대로 보존합니다. [v2-QA](docs/v2-QA.md)는 최신 기록과 이전 관찰을 구분합니다. [독립 비평](docs/v2-independent-critique.md)과0.94 등급은 각각 당시 자료의 평가이며 현재 후보의 품질 승인이 아닙니다. 새 단계의 부모 운영 한도32회(사용자 금액 예산 아님)는 모두 사용했습니다. 24회 저장 성공/8회 실패의 입력·원응답·상태·코드 해시를 보존하며 추가 승인 없이 유료 검증을 자동 실행하지 마세요.

여러 구현 버전에 걸친 과거17턴 로맨스에서 기억·거절·고백·연인·데이트 시작·이동·새 약속 이행을, 대비되는 직장 흐름에서 미합의와 성공을 관찰했습니다. 현재는 데이트 참여와 완료를 별도 검증하므로 옛 완료 횟수를 새 규칙의 실검증으로 세지 않습니다. 사건 누락·주체 혼동 사례와 남은 한계를 보고서에 보존했습니다. 모든 미션/결말의 실제 AI 대화 품질이나 상용 출시 수준을 보증하지 않습니다. 음악은 디코딩·재생·전환을 검사했으나 사람의 감상 평가는 별도입니다.

재현 가능한 무료 검사:

```powershell
npm test
npm run build
npx playwright install chromium
npx playwright test
```

기본 브라우저 검사는 v2 화면·에셋·음악·저장 회귀를 대상으로 하며 격리된 mock 서버를 사용합니다. 예전 선택지 기반 테스트는 역사 자료로 남아 있습니다. `tests/v2-live-smoke.ts`는 일반 검사에 포함되지 않으며 이미 소진된 원장 한도에서 추가 호출을 거부합니다.

## 에셋·라이선스·배포

전체 화면 원본 배경, 박도현·서유나 각 12개 그림 포즈와 8개 오리지널 음악을 사용합니다. 윤서진 부장의 네 가지 포즈와 생성 프롬프트는 [직장 캐릭터 에셋](public/assets/office/generation.json)에 있습니다. 원본과 출처·프롬프트는 `public/assets/generation-manifest.json`, `public/assets/v2/generation-manifest.json`, `public/assets/audio-v2/manifest.json`에 있습니다. v1 원본은 보존했습니다. 음악은 8초 최소 유지와 2초 크로스페이드를 적용합니다. 외부 폰트 요청 없이 시스템 글꼴을 사용합니다.

`THIRD_PARTY_NOTICES.txt`는 실행 의존성 68개의 라이선스 원문입니다. 의존성 변경 시 `node scripts/generate-notices.mjs`로 갱신하세요. 로컬 배포는 빌드 후 `powershell -File scripts/package-local.ps1`로 `artifacts/AFTER-HOURS-local.zip`을 만듭니다. 키·개인 저장·node_modules는 제외됩니다. 공개 배포·스토어 등록은 수행하지 않았습니다.

플레이에 필요한 파일만 묶으려면 빌드 후 `powershell -File scripts/package-playable.ps1`를 실행하세요. `artifacts/AFTER-HOURS-playable.zip`에는 소스·그림·음악·실행 파일·사용 안내와 파일별 해시 목록이 들어갑니다. 전체 검증 기록은 개발본에 보존합니다. 약66MB의 첫 실행 패키지를 새 폴더에 설치해 빌드·시작·재시작·실제 화면·종료를 확인했습니다. [설치 검증의 정확한 버전과 범위](docs/v2-playable-install/README.md)를 참고하세요.

패키지 생성 후 `& ./scripts/audit-current-package.ps1`로 전체 포함 파일과 현재 프로젝트의 바이트·해시, 누락과 개인 파일 제외를 대조할 수 있습니다. 감사 결과는 ZIP 입력 밖인 `artifacts/`에 새 JSON으로 보존합니다. 이 검사는 실제 설치·생성 대화 품질·출시 승인을 대신하지 않습니다.
