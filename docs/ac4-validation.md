# AC4 대화 처리 수리 검증 — 2026-11-21

이 문서는 이전 AC4의 고정 대사·버튼 전용 구현 설명을 대체한다. 구현과 자동 회귀 검증은 완료했지만, **실제 모델의 취향 귀속 품질은 부분 확인**이다. 완전한 출시 승인이나 모든 한국어 표현의 정확성을 주장하지 않는다.

## 구현

- Responses API에 developer 인물 설정·장면 지문·서버 확정 사건, user 플레이어 발화, assistant 실제 생성 대사를 분리하여 전달한다. 저술된 지문을 assistant 대사로 넣지 않는다. 제안 답변도 실제 선택 문장을 user 이력으로 보존한다. 유나는 시나몬 맛을 싫어하고 향을 좋아한다는 인물 설정을 명시한다.
- live line은 enum이 아닌 1–600자 자유 생성 한국어다. 모델은 현재 반론의 알려진 논거 ID 또는 현재 로맨스 장면의 행동 ID, none 중 하나만 분류한다. 서버가 ID를 재검증하고 합의 조건·중복 의미·순서·턴 제한·관계·엔딩을 결정한다. 사용자 원문은 그대로 기록한다. 임의 점수/상태/엔딩 필드는 거부한다.
- live none은 키워드 매칭으로 다시 수락하지 않는다. 질문·가정이 단어만 포함했다는 이유로 진행하지 않게 했다. 로컬의 명시적 고백 거절은 모델의 수락 해석보다 우선한다. offline은 기존 결정론적 규칙과 명시적인 OFFLINE DEMO 표시를 유지한다. 일반 한국어 이해가 동등하다고 주장하지 않는다.
- API 키는 서버 .env/프로세스 환경에만 존재한다. 모델 환경변수, 700 출력 토큰, strict JSON schema 및 로컬 재검증, 500자 입력, 세션 100회/프로필 시간당 300회, 동시 요청 잠금, 10초 timeout, 취소, 같은 requestId 재시도 및 오류 표시를 유지한다. 실패를 offline 성공으로 대체하지 않는다.
- 공식 자료 재확인: [Responses quickstart](https://developers.openai.com/api/docs/quickstart), [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs).

## 실제 관찰과 남은 품질 한계

7번: 정상 직장 새 게임에서 `요약은 지금 보내둘게요. 여섯 시에는 약속 때문에 나가야 합니다.`를 제출했다. 부장이 직접 존댓말로 답하고 leave=오늘 18:00이 확보됐다. 잔여 책임 조건은 미확보, 엔딩은 없음. 버튼 번호나 상태 주입으로 만든 결과가 아니다.

8번: 정상 로맨스 새 게임에서 **offline 1턴**으로 빗소리·귤 취향과 종소리 공동 청취를 기록한 뒤 live로 전환했다. 기억 질문과 헤드폰 반납에 실제 한국어 대사가 빗소리와 귤을 정확히 회상하고 반납을 언급했다. 플레이어를 유나로 부르지 않았다. 서버는 headphone-return/shared-test를 확정하고 다음 장으로 진행했다.

그러나 모델은 시나몬에 관해 “시나몬은 향만 좋고 맛은 싫다는 거, 확실히 기억하고 있어요!”라고 답했다. 이는 인물 취향 내용은 맞으나 소유 주체를 명시하지 않은 표현이다. 사용자 요청대로 두 사람 취향을 명확히 구분했다는 완전 통과 근거로 쓰지 않는다. 또한 당시 공동 청취 정본에 플레이어가 커피를 모른다고 덧붙이는 기존 과잉 사실이 발견됐다.

실응답 관찰 후 주체를 “당신은/저는”으로 명시하는 프롬프트를 보강하고, 공동 청취 사건에서 주장하지 않은 커피 취향을 제거했다. live none 키워드 재해석도 차단했다. 회상 ID는 model_dialogue의 recallIds 메타데이터에 보관하고, 전체 도입 지문을 생성 대사 뒤에 붙이지 않도록 수정했다. mock 응답으로 대사/메타데이터 분리와 공동 청취의 과잉 귀속 방지를 검사했다. 이 최종 변경은 build/85개 테스트로 검증했으나 **남은 예산이 없어 실제 API 재검증은 하지 않았다**. 당시 실응답 해시와 최종 소스 해시는 의도적으로 다르다. 전체 대화 흐름의 live 검증, 모호한 취향 귀속의 개선 여부는 미확인이다.

## 범위

수정 파일은 서버 대화/의도 처리와 관련 테스트·문서다. 원본 아트와 동시 작업 중인 연출 파일은 변경하지 않았다. 생성 대사의 의미적 정확성은 schema만으로 보장되지 않는다. AC4의 완전한 품질 통과는 보류한다. 추가 paid 호출 없이 현재 증거 이상의 성공을 주장하지 않는다.
