# AC 6 — 저장과 원자적 턴 확정

2026-11-21 검증. 대상은 AC 6이며 전체 제품 출시 준비도를 판정하지 않는다.

## 구현

`server/storage.ts`는 형식 버전, SHA-256 체크섬, 프로필 구조를 검증한다. 같은 디렉터리의 임시 파일에 전체 프로필을 기록하고 파일 sync/close 후 rename으로 교체한다. 교체 전 유효본은 `.bak`에 보관한다. 프로필에는 자동 저장, 세 수동 슬롯, 해금, 요청 횟수, 영속 요청 기록이 함께 들어 있다. 요청 기록은 새 게임과 슬롯 복원 후에도 남는다.

서버는 입력 및 AI 응답 검증과 서버 상태 전이 후 요청 ID, 입력 해시, 전후 버전, 검증 응답, 정본 사건, 로그, 해금 변경, 반환 결과를 한 프로필로 확정한다. 실패한 API 시도는 요청 예산만 소비하며 이야기 상태를 변경하지 않는다. 확정된 요청의 재전송은 provider 호출 및 요청 예산 소비 없이 현재 저장 상태를 반환한다. 이후 다른 턴·새 게임·슬롯 복원이 있었다면 409와 현재 상태로 화면을 동기화한다. 다른 입력의 ID 재사용과 오래된 버전의 새 선택도 409 및 현재 상태를 반환한다. 기존 세션 잠금과 요청 제한을 유지한다.

수동 복원은 장/턴/관계/증거/합의/엔딩/로그를 저장 시점 그대로 복원한다. 전송용 dialogue.version만 단조 증가시켜 복원 전 탭의 선택을 거부한다. 새 게임에도 이 버전을 재사용하지 않는다. 화면 표시 실패는 서버 확정을 취소하지 않는다. 브라우저는 미확인 턴을 sessionStorage에 보관하여 새로고침 후 같은 요청을 재전송한다.

손상 또는 지원하지 않는 저장 형식은 마지막 유효본으로 복구하고 안내한다. 유효본도 없으면 진행을 차단하고 사용자가 확인 후 실행할 수 있는 저장 초기화를 제공한다. 기존 체크섬 없는 구형 파일은 임의로 신뢰하거나 변환하지 않으며 동일한 복구/초기화 경로를 제공한다.
