## 수정과 로컬 검증

`server/office.ts`에서 유효한 정시 퇴근 의도가 분류된 경우 별개의 야근 거절을 제안 전체의 철회로 처리하지 않도록 범위를 나눴다. 요약본 자체의 거절, 조작 지시, 연장근무와의 모순은 계속 거부한다. `server/boundaries.test.ts`의 정상 표현 3개와 거절/조작 대비 4개를 통과했다. 이는 분류 결과를 mock으로 넣는 서버 회귀 검증으로, 모델의 모든 한국어 해석 능력을 보증하지 않는다.

이후 `npm run build`(타입 검사 포함)와 `npm test`를 실행해 **110/110 통과, 실패 0, 건너뜀 0**을 확인했다. 이전 단계의 브라우저·저장 증거는 별도 AC 문서에 보존돼 있다. 최종 Ralph에서는 통합본의 브라우저 및 명세 충족을 다시 판단해야 한다.

## 실제 API 검증

부모가 정한 초기 8회 운영상한을 사용자에게 알린 뒤, 사용자의 API 키 사용 및 완성까지 계속하라는 위임 범위에서 최대 4회 추가 검증으로 조정했다. 사용자 지정 예산이 있었던 것으로 표현하지 않는다. 실제 생성된 후속 Seed에 누적 최대 12회를 기록했고 원장의 기존 1–8번을 보존했다. 추가 호출 전에 회귀 검증을 통과했다.

명령: `npx tsx tests/final-live-smoke.ts --execute-authorized-smoke` — 종료 코드 0. 공식 Responses API, 네 요청 모두 HTTP 200 및 schema/server 검증 통과. **누적 12/12**, 추가 유료 호출은 하지 않는다. 이 테스트는 일반 test/Playwright 명령에 포함되지 않는다.

| 시도 | 정상 플레이 입력 | 실제 결과 |
|---|---|---|
| 9 | 야근을 할 수 없지만 요약본은 지금 보내고 여섯 시 퇴근 제안 | 부장이 직접 답하고 `leave=오늘 18:00` 확보. 잔여 담당 미확보라 아직 엔딩 없음 |
| 10 | 직전 상태에서 남은 표를 부장이 내일 오전 열 시까지 맡도록 제안 | 부장이 자신이 맡겠다고 답하고 담당·기한 확보. `office-clockout-success` 도달 |
| 11 | 정상 로맨스 새 게임에서 공동 종소리 청취와 빗소리·귤 취향 대화 | 새 문장으로 답하고 플레이어 취향을 반영. 플레이어를 유나로 부르지 않음 |
| 12 | 직전 상태에서 소리·간식 및 유나의 좋아하는 향을 질문하고 헤드폰 반환 | “당신은 빗소리와 귤… 저는 시나몬 향…”으로 주체를 명시. 헤드폰 반납이 확정됨 |

네 입력은 `choice:null` 자유 대화이며, 정상 공개 API의 새 게임·진행 경로를 이용했다. offline prefix나 게임 상태 주입이 없다. 실제 답변, 초기/최종 상태, 요청, 각 파일 SHA256은 `final-live-evidence.json`에 있다. 의미 검토를 연결/schema 통과와 구별해서 위 표에 기록했다.

이 증거는 두 대화 흐름의 집중 검증이다. 모든 임의 한국어·장시간 대화·모든 미션/엔딩을 live로 검증했다고 주장하지 않는다. 생성 대사는 확률적이며 실제 기기 IME, 다른 브라우저, 사람의 장시간 플레이 및 스토어 제출은 별도 범위다.

## 실행 패키징

`play.cmd`는 필요한 의존성 설치·빌드·숨김 로컬 서버 실행 및 브라우저 열기를 처리한다. `stop.cmd`는 이 프로젝트가 기록한 PID와 실행 경로를 대조하고 해당 서버만 종료한다. Windows 스크립트 구문 검사와 실제 설치/빌드/서버 시작을 확인했다. 원래 폴더의 저장 데이터는 `.local-data`에 있다.

실행 의존성 68개의 원문 라이선스를 `THIRD_PARTY_NOTICES.txt`에 보존했다. 초기 npm 감사에서 보고된 취약점은 0개였다. 원본 에셋의 생성 프롬프트·출처는 기존 manifest에 유지한다. 이 문서는 법률 또는 상업 출시 적합성에 대한 보증이 아니다.
