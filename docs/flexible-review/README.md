# 자유 대화와 내부 답변 재작성

2026-11-21. 사용자가 승인한 [수정 기준](acceptance.md)에 따라 “네 선택지를 주세요”처럼 정상적인 입력을 플레이어가 고치게 만들던 처리 경로를 변경했다. 전체 목표는 일시정지를 유지했고 Ralph를 재개하지 않았다. 추가 유료 API 검증 호출은 0회이며 기존 원장과 공식 판정을 유지한다.

## 바뀐 동작

OpenAI 응답을 `utterance`(대사·동작·표현)와 `changes`(실제 사건·약속 기록 또는 null)로 분리했다. 일반 질문·농담·망설임·화제 전환은 사건 기록 없이 대화 이력으로 저장할 수 있다. 별도의 의도 선택이나 목표 충족이 필요하지 않다. 새로운 합의나 실제 행동은 기존 정본 엔진에서 계속 검증한다. 이 구분은 입력을 몇 가지 고정 답안으로 분류하는 장치가 아니다.

AI 초안의 형식이나 사건 검증이 실패하면 원래 입력과 변경 전 상태로 전체 답변을 한 번 재작성한다. 실패한 초안은 대화 로그·화면·확정 사건에 들어가지 않는다. 거절된 상태 변경만 삭제하고 동일한 결과 선언을 그대로 재사용하는 직접적인 경우도 차단한다. 실제로 타당한 새 합의를 수정된 답변에 유지할 수 있으며, 수정된 전체 답변만 한 턴으로 저장한다. 대사 의미의 모든 모순을 일반적으로 증명하는 검증기는 아니므로, 표현을 바꾼 허위 주장까지 완전히 검출한다는 뜻은 아니다.

정상 대화는 호출 1회, 재작성까지 필요하면 최대 2회다. 각각 호출 전 시도 수를 저장하고 1600토큰 상한, 게임당 100회 시도 한도, 기존 시간당 한도를 적용한다. 한 턴 전체에 30초 제한과 취소 신호를 공유한다. 네트워크·저장·한도 실패와 명시적인 모델 거절은 자동 재작성하지 않는다. 두 번 모두 실패하면 이전 상태와 원래 입력을 유지하며, 플레이어에게 입력을 고치라고 요구하지 않는다. 자동 오프라인 대사나 가짜 성공은 없다.

화면에서는 ‘지금의 목표’와 합의 개수를 없애고 장·장소·현재 상황을 설명한다. AI 지시도 방금 건넨 말에 먼저 반응하고 매번 목표로 되돌리지 않도록 바꿨다. 방법이나 선택지를 물으면 인물이 말로 대안을 제시하되 수락으로 간주하지 않는다. 체크리스트를 채우는 방식 대신 상황과 인물의 반응으로 장면을 이어가도록 했다. 기존 합의·연인·데이트·결말의 실제 성립 조건은 유지한다.

## 검사와 실행 확인

- 전체 단위/HTTP 검사 399개 통과 후, 실제 새 합의를 보존하면서 잘못된 추가 이동만 재작성하는 검사 하나를 추가했다. 관련 검사 9개 재실행 통과로 서로 다른 400개 케이스를 확인했다. 제품 소스는 두 실행 사이 변경하지 않았다.
- 전체 브라우저 검사에서 34개 통과, 새 PC 테스트 하나 실패. 테스트가 새 게임 저장 완료를 기다리지 않고 `/state`를 읽어 초기 상태가 없었던 경합이었다. 입력창이 나타난 뒤 상태 HTTP200을 확인하도록 고치고 PC·모바일 두 케이스를 다시 실행해 통과했다. 서로 다른 35개 시나리오를 확인했으며 실패 결과도 보존했다.
- 실제 HTTP와 브라우저에서 플레이어 전송 1회 → 잘못된 모의 초안 → 동일 입력의 내부 재작성 → 저장 1회를 확인했다. 부당한 옥상 이동/퇴근 선언은 화면과 로그에 남지 않았다. 이어서 커피 농담을 보내도 합의 조건 없이 저장됐고 새로고침 후 유지됐다. 질문·농담·망설임·화제 전환을 각각 검사했다.
- 수정 후에도 새로운 업무 대안의 합의, earned-state 부정 대조군, 요청 ID 재전송, 세 슬롯, 중간 취소, 호출 한도, 오류 후 진행 불변을 확인했다. 재작성 두 번 실패 시 호출이 늘어나지 않았고, 제한이 한 번 남았을 때 추가 호출을 하지 않았다. 기존 2D 포즈, 음악 재생/전환, 긴 대사 페이지, 입력 가시성 검사도 유지했다.
- 원본 실행기로 서버를 재빌드·재시작했다. `http://127.0.0.1:3001/`의 HTTP200과 빌드 HTML을 대조하고, 새 테스트 브라우저 컨텍스트에서 두 모드의 시작 화면을 직접 확인했다. 실제 서버에는 대화 턴을 보내지 않았다. 기존 플레이어의 쿠키/저장은 유지하며 별도 새 테스트 프로필만 생성했다.
- 플레이 ZIP은 123개 파일, 65,832,128바이트, SHA-256 `67e2b47ff0bd8a457449977f5f5c5331b191107287186e2d104d666fc8dd3374`. 현재 파일과 바이트/해시 일치 및 키·개인 저장 제외 감사를 통과했다. 직전 92939f9 패키지는 artifacts/history에 보존했다. 별도 새 폴더 설치 검사는 이번 범위에 포함하지 않았다.

새 스키마의 로컬 계산상 최대 컨테이너 중첩은 6단계다. 공식 문서의 중첩 한도와 객체 내부 `anyOf`/null 지원을 확인했다. 이는 실제 모델 호출로 수락을 확인한 증거와 구별한다. [OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs)
