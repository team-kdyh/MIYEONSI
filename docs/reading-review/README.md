# 대사 읽기 · 복구 안내 · 현재 이야기 목표

2026-11-21. 사용자가 제보한 대사 스크롤, 내부 오류 문구, 현재 단계와 중심 이야기 안내 부족을 수정했다. 일시정지된 전체 목표와 종료된 Ralph 작업은 재개하지 않았다. 유료 모델 호출은 0회다.

대사 창의 고정 높이를 없앴다. 짧거나 중간 길이의 답변은 필요한 만큼 창을 늘려 동작 지문·대사·입력을 함께 보여 준다. 화면 높이를 넘는 긴 답변은 실제 글꼴과 너비로 측정해 페이지로 나눈다. `계속 읽기`는 스토리 선택지가 아니라 같은 답변의 다음 부분이며 이전 부분, 방향키, PageUp/PageDown, Home/End를 지원한다. 글자나 동작 지문을 버리지 않는다. 모바일 큰 글씨와 390×500 화면에서도 입력과 얼굴을 유지한다.

문제의 문구는 AI가 제안한 사건·약속을 서버가 검증하지 못했을 때 내부 예외를 그대로 내보내고, 클라이언트가 모든 오류에 전달 여부 확인 문구를 덧붙여 생겼다. 이제 저장 전 거절은 `reply_rejected / committed:false`로 구분한다. 플레이어에게는 이전 진행과 입력이 보존됐다는 짧은 안내와 `답변 다시 받기 / 말 고치기`를 대화 창 안에 표시한다. 전달 여부가 불명확한 연결 오류는 `이어받기 / 진행 불러오기`로 처리하며 원래 요청 ID를 유지한다. 검증을 우회하거나 실패를 오프라인 성공으로 바꾸지 않는다.

현재 장·장소·목표·진행 안내는 저장된 정본 상태에서 계산한다. 직장은 실제 합의한 항목 수와 남은 항목, 로맨스는 현재 관계·데이트 참여/완료·확인된 단서를 반영한다. 앞으로의 반전이나 미발견 결말은 첫 화면에 노출하지 않는다. 같은 상태에서 계산한 다음 이야기 방향을 AI의 developer 메시지에도 전달한다. 자유 대화에 반응하면서 중심 화제로 돌아오되, 횟수만으로 장을 넘기거나 플레이어의 고백·행동을 대신 쓰지 않도록 했다. 가벼운 취향 대화에 불필요한 복잡한 약속을 만들지 않도록 지시했다.

## 검증

- 단위/HTTP 검사 **391개 통과**, 타입 검사와 빌드 통과. 스키마 오류·사건 오류·약속 오류에서 진행 불변, 입력 재시도와 한 번만 저장, 실제 타이머 취소/시간초과, 저장 복구를 검사했다. 7턴의 자유 대화만으로 단계가 강제 변경되지 않으며 저장 복구 후 목표도 같은 상태에서 계산된다.
- 브라우저 **33개 시나리오 통과(전체 실행 32개 + 수정한 테스트의 표적 재실행 1개)**. 전체 실행에서 한 곳은 예전 `같은 요청 다시 시도` 버튼 이름을 찾다가 실패했다. 그 선택자를 `이어받기`로 바꾸고 실제 0/2→1/2→2/2→에필로그 목표 표시 검사를 추가한 뒤 해당 여정을 재실행했다. 두 실행 사이 제품 소스 변경은 없다. 전체 실행의 실패 원문은 지우지 않았다.
- 1440×623, 1280×720, 390×844에서 제보와 비슷한 길이의 대사가 한 페이지에 모두 표시됐다. 긴 대사·동작 지문의 페이지를 모두 이어 붙여 원문과 정확히 일치함을 검사했다. 큰 글씨 390×500에서도 확인했다. 기존 인물 포즈, 실제 오디오 파일 재생과 전환, 세이브·엔딩·재시작도 검사했다.
- 원본 실행기로 3001 서버를 중지·재빌드·재시작했다. 실제 빌드와 HTTP200을 대조하고 새 브라우저 컨텍스트에서 두 모드의 첫 화면을 확인했다. `/api/turn`은 보내지 않았다. 개인 브라우저 쿠키와 저장은 건드리지 않았다.
- 최신 플레이 패키지는 121개 파일, 65,829,089바이트. SHA-256 `334f0519b7b69a72c71b53fbd63734d04f1106bfb647b8c236d89b02a53a173c`. 파일별 현재 소스 일치와 비밀/개인 저장 제외 감사를 통과했다. 직전 ee73a94 패키지는 artifacts/history에 보존했다. 이번 패키지의 별도 새 폴더 설치 검사는 하지 않았다.

초기 단위 실행에서 2개 테스트는 새 파생 표시 필드와 추가 developer 메시지 때문에 정확한 비교가 실패했다. 테스트가 정본 저장과 파생 정보를 구분하고 역할 경계를 계속 검사하도록 수정했다. 초기 389/391 결과도 보존한다.
