# 독립 QA 보강 검증

최초 독립 Ouroboros QA는 0.89로, 부모가 설정한 0.90 기준에 미달했다. 새 기능 결함은 보고하지 않았으며 잘못된 입력 경계, 연속 중단 복구, 시간에 민감한 브라우저 검사의 반복 증거를 요구했다. 아래 검사는 같은 실행 코드에 대해 수행했다. 게임 서버·프런트엔드·provider 로직을 변경하지 않았으며 추가 유료 호출은 0회다.

## HTTP 입력 경계

`server/adversarial.test.ts`는 빈 API 키와 offline 제공자를 사용하는 실제 임시 HTTP 서버를 기동한다. 빈 문자열·공백·null·숫자·불리언·배열·객체·501자·잘못된 JSON 및 JSON primitive를 거부하고, 매번 공개 상태 전체의 SHA256이 이전과 같음을 확인했다. 500자는 수락해 정확히 한 턴 진행했다. UTF-8 요청 본문을 정확히 4096바이트와 4097바이트로 만들어 각각 수락/거부를 확인했으며, 거부 후 상태는 변하지 않았다.

총 13개 관찰이 `supplemental-input-evidence.json`에 기록된다. HTTP 응답 상태, 바이트 수, 이전/이후 상태 해시 및 진행 차이를 포함한다.

## 연속 저장 중단과 재시작

정상 새 직장 게임에서 두 턴 각각에 다음 순서를 적용했다: 확정 전 실패 → 서버 재시작 → 같은 요청의 확정 후 응답 유실 → 서버 재시작 → 같은 요청 세 번 재시도. 총 중단 4회, 실제 프로세스 재시작 4회, 중복 재시도 6회다.

확정 전 실패에서는 상태 전체가 유지되고, 확정 후 재시도에서는 저장된 상태 전체가 동일했다. 저장 저널을 읽기만 하여 요청 ID마다 확정 기록이 하나임을 확인했다. 최종 턴은 2, 확정 기록은 2개, 칼퇴 성공 엔딩 해금은 1개였다. 결과는 `supplemental-interruption-evidence.json`에 있다. 프로세스 재시작과 지정된 저장 경계의 장애 주입이며 임의 전원 차단 실험으로 표현하지 않는다.

## 반복 브라우저 검증

아래 명령을 3회 실행했다. 매 실행은 설정에서 생성하는 별도의 `.ralph/ac7-final/data-{timestamp}` 폴더와 새 서버/브라우저 컨텍스트를 사용한다.

`npx playwright test tests/presentation.spec.ts tests/persistence.spec.ts tests/ac7.spec.ts --config playwright.ac7-final.config.ts`

| 실행 | 결과 | Playwright 시간 | 전체 명령 시간 |
|---|---|---|---|
| 1 | 10/10 통과 | 40.5초 | 42.49초 |
| 2 | 10/10 통과 | 38.5초 | 39.52초 |
| 3 | 10/10 통과 | 38.2초 | 39.22초 |

취소·오류 복구·세이브·오래된 상태, 오디오 playing/효과음·음소거, 타이핑·효과 감소, 입력·키보드·두 해상도 및 대표 엔딩을 검사했다. 각 실행의 대표 네 UI 완주는 console/page 오류 0을 단언한다. 반복마다 연출·대화·복구 증거 JSON을 `repeat-{1,2,3}-*.json`으로 보존했다. 반복 요약은 `supplemental-browser-repeats.json`, 원본 출력은 `repeat-{1,2,3}-browser-run.txt`다. 이전 스냅샷도 `before-repeats-*.json`에 보존했다.

## 전체 검사

`npm run build`와 전체 `npm test`를 다시 실행했다. 타입 검사·배포 빌드 및 **112/112 테스트**가 통과했다. 로그는 `supplemental-build-run.txt`, `supplemental-unit-run.txt`, 별도 HTTP 검사 로그는 `supplemental-http-run.txt`다. 기존 전체 브라우저 18/18 통과에 더해 위 시간 민감 검사 30회가 모두 통과했다. 유료 API 원장은 계속 12/12다.

이 결과는 최초 독립 QA의 세 가지 증거 요청에 대한 응답이다. 원래 Ralph의 6/7 및 경로 검사 오류 기록을 바꾸지 않으며, 실제 기기 IME·다른 브라우저·사람의 장시간 플레이·공개 스토어 심사를 수행했다고 주장하지 않는다.
