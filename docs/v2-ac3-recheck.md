# AC3 재검증 — 2026-11-21

판정: **부분 수정 및 결정적 검증 완료, AC3 전체 승인 보류**. 실제 모델로 여덟 미션 각각의 대조 흐름과 네 로맨스 결말을 관찰한 증거가 없다. v2 추가 32회(기존 v1 포함 누적 44회)는 소진됐으며 이번 실행의 추가 유료 호출은 0회다. 원장, 원본 실응답, 개인 저장, 기존 QA 판정은 변경하지 않았다. 중첩 auto나 세션 signal도 실행하지 않았다.

## 재현 가능한 결함과 수정

기존 `relationship/date accepted`는 현재 장소가 카페 등이고 연인 관계이면 즉시 `dates++`했다. 실제 기록 29번도 대사가 “데이트가 시작되는 기분”이고 사건 내용이 “데이트를 시작함”인데 완료 횟수가 1이 됐다. 약속 수락과 경험 완료를 구분하는 AC에 맞지 않는다.

- 미래 데이트 수락은 사건 기록만 남긴다. 현재 참여 의사가 명시된 accepted는 `activeDate`에 시작 사건 ID·장소·턴을 기록하고 완료 횟수를 올리지 않는다.
- 같은 장소의 별도 후속 턴에서 사용자 근거와 NPC 행동이 있고, 시작 사건을 reference로 연결한 fulfilled가 있을 때 완료를 기록한다. 장면 이탈, 해당 데이트 거절, 결별은 진행 중 장면을 해제한다. 완료 재전송과 시작/완료를 같은 턴에 처리하는 것을 차단한다.
- `activeDate`는 슬롯/자동 저장에 함께 보존되며 저장 검증은 시작 사건·턴·장소·연인 상태를 대조한다. 이 필드가 없는 이전 저장도 읽는다. 이전 저장의 dates를 삭제하거나 과거 경험이 새 계약에서 검증됐다고 재분류하지 않는다.
- reset/repeat 결말과 진실 장면은 offered/refused 단서로 열리지 않도록 fulfilled 단서를 요구한다. restore는 서로 다른 두 fulfilled 단서 조건을 유지한다.
- provider의 구조화 출력과 지침을 이 수명주기에 맞췄다. 따라서 **이전 provider 해시의 실호출은 새 지침이 실제 모델에서 잘 작동한다는 증거가 아니다**.
