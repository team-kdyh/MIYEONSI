# 부모 통합 검토 — 출시 승인 아님

2026-11-21. 첫 실제 Ralph 반복은 generation2에서 `grade_regressing`으로 끝났다. 공식3/7, 별도 QA0.58/REVISE 원문은 `../v2-ralph-terminal.json`에 있다. 기준이나 판정기를 수정하지 않았다.

부모는 generation2 구현이 종료된 후508개 파일을 원래 실행 폴더로 바이트 동일하게 복사했다. 기존24개 변경 파일은 `.ralph/v2-integration/before/`에 백업했고, 전체 과거 docs553개도 `g2-evidence-before-parent-checks.zip`에 보존했다. 원래 Ralph 작업트리는 그대로 남겨 두었다. 개인 `.env`와 저장은 복사하거나 지우지 않았다. 두 호출 원장과32개 실제 원응답은 보존했다.

추가 수정: 긴 대사 다음 새 답변의 스크롤 초기화와 넘침 안내, 모바일 타이틀의 두 모드 노출, 브라우저32초 대기, 도달 가능한 컬렉션과 기존 해금 보존, 현재 실제 에필로그 우선 표시, UI→HTTP→가짜 외부 응답의 취소/동일 요청 재시도/직장 결말 여정. 일반적인 미래 문장과 현재 데이트를 분리하고, 원 약속의 수행자를 수락자와 구별하며 명시적 미완료와 미래 약속의 완료 기록을 차단했다. 조사를 생략한 자연스러운 완료 표현도 유지한다.

추가 재현에서 이전 구현은 명시적 고백 뒤의 `네`, `응`을 한 글자라는 이유로 거절했고, `지금` 데이트 제안의 정확한 ID를 참조한 `좋아요`도 참여를 시작하지 않았다. 이제 짧은 긍정은 관련 기존 제안/고백과 모델의 별도 사건 제안이 있을 때 인정한다. 이 규칙이 대사나 장면을 선택하지 않는다. 질문·인용·보류는 차단하며 미래 제안 수락은 데이트 완료가 아니다. 정확한 재현과4개 회귀는 `short-reply-before.json`, `server/narrative-short-reply.test.ts`에 있다.

검사 결과: 빌드/타입 통과, 단위244/244, 기본 브라우저25/25, 향후 QA 승인 차단기8/8. 화면 검사는 실제 브라우저 렌더링과 격리된 가짜 Responses transport를 사용했다.13초 지연 응답도 실제로 기다려 정상 표시를 확인했다. 새 유료 API 호출은0회다. 화면과 단위 통과를 실제 생성 품질로 바꾸어 말하지 않는다.
