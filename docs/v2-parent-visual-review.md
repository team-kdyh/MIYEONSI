## 요구에 부합하는 개선

1. 본 플레이 화면에 흰색/크림색 페이지 영역이 없고 배경이 화면을 채운다. 이전의 문서·폼 화면에서 비주얼 노벨 무대로 인상이 바뀌었다.
2. 선택지나 합의 체크리스트가 보이지 않는다. 캐릭터, 짧은 지문·대사, 플레이어 입력의 순서가 명확하다.
3. 1440×900 및 390×844 캡처 모두 얼굴과 입력란·전송 버튼이 동시에 보인다. 확인한 화면에서 얼굴을 가리는 대화 상자나 가로 잘림은 발견하지 못했다.
4. 어두운 반투명 대화창과 밝은 본문, 이름 표기가 안정적으로 읽힌다. 포커스 테두리도 분명하다. 공포 장면의 색·배경 변화가 과장된 효과 없이 분위기를 바꾼다.
5. 설정 모달은 데스크톱/모바일 모두 화면 내에 들어오고 닫기, 체크박스, 음량, 읽기 속도, 재시작이 구분된다.

## 우선 수정할 실제 시각 결함

### P1 — 캐릭터 원본 종횡비가 보존되지 않음

타이틀 데스크톱에서 유나의 얼굴/몸이 가로로 넓고 모바일에서는 좁게 보인다. 이는 단순한 개인 취향 문제가 아니다. 원본 시트의 한 셀은 **543×724, 비율 0.75**인데, `.title-character`는 `inset:12% -2% 0`으로 컨테이너에 맞춘 임의 폭·높이를 만든 뒤 `background-size:400% 100%`로 독립적으로 늘린다. 모바일의 `inset:0 15% -45%`도 같은 문제를 만든다.

본 플레이의 `.sprite` 역시 모바일에서 `width:86vw`, `height:67%`를 동시에 사용한다. 390×844 기준 약335×565(비율0.59)여서 원본보다 가로로 약21% 압축되는 조건이다. 데스크톱은 우연히 원비율에 가깝고 화면 높이가 달라지면 다시 변할 수 있다.

**권장:** 시트 한 셀의 `aspect-ratio:543 / 724`를 고정하고 높이 또는 폭 한 축만 결정한다. 각 시트의 여백 보정은 별도 균등 scale/offset으로 처리한다. 데스크톱·모바일·가로 화면에서 얼굴 비율 비교 캡처를 다시 남긴다. 캐릭터 정체성과 아트 품질에 직접 영향을 주므로 전달 전 수정 권장이다.

### P2 — 장문에 숨겨진 내용이 있다는 표시 부족

장문 포커스 캡처는 얼굴·입력을 유지한다는 장점이 있으나, 데스크톱 본문이 문장 중간에서 시작하고 모바일은 하단 한 줄이 절반 잘려 보인다. 정지 화면만으로 본문이 실제 유실된 것인지, 내부 스크롤의 중간 상태인지는 구분할 수 없다. **본문 유실로 단정하지 않는다.** 다만 이용자에게는 텍스트가 잘린 것으로 보일 수 있다.

**권장:** 긴 대사 전체를 키보드/터치로 읽을 수 있는지 실제 조작 검증하고, 내부 스크롤 표시나 위·아래 페이드/더 읽기 표시를 둔다. 새 응답 시 시작점과 입력 포커스 시점의 스크롤 정책을 분리해 첫 문장을 놓치지 않게 한다. 모바일 소프트웨어 키보드가 올라온 상태는 이 캡처에 없으므로 별도로 확인해야 한다.

### P2 — 지문 동작과 눈에 보이는 포즈가 아직 분리되어 있음

유나 캡처의 지문은 “컵을 감싸 쥐고 웃는다”인데 시각 포즈는 팔을 내린 중립 표정이다. 부장 지문은 “펜을 내려놓는다”인데 서류를 든 중립 포즈다. 이 단계의 mock/기존 4표정 테스트만으로 새 16개 동작 통합이나 행동-포즈 일치가 증명되지는 않는다.

**권장:** 새 동작 시트 통합 후 듣기·웃음·머뭇거림·시계·서류·녹음기·집착 등의 대표 지문과 실제 sprite ID/표정이 맞는 장면을 관찰한다. 사용자가 요청한 “대사뿐 아니라 동작”의 체감에 직접 관련된다. 모든 세부 지문을 그림으로 재현할 필요는 없지만 상태가 매번 같은 중립 포즈에 머물면 요구 미달이다.

## 개선하면 좋은 구성

- **모바일 타이틀:** 390×844 첫 화면에 로맨스 시작 버튼은 아래로 밀리고 직장 버튼만 보인다. 화면 이동으로 접근 가능할 수 있어 기능 장애로 보지는 않지만, 두 모드가 동등한 진입점으로 보이도록 상단 그림/제목/소개 간격을 줄이는 편이 좋다.
- **짧은 대사의 큰 빈 공간:** 데스크톱 대화창은 짧은 두 문장 아래에 넓은 빈 영역이 남는다. 위치를 안정적으로 유지하려는 의도는 이해되지만, 상용 VN 특유의 압축된 대사 리듬보다 큰 폼 같은 느낌이 약간 남는다. 대사 영역 높이를 줄이거나 최근 플레이어 발화를 작은 말풍선으로 표시할지 검토할 수 있다. 단, 얼굴/입력 안정성을 희생하지 않는다.
- **상단 정보 밀도:** 모바일의 모드·영문 부제·장 제목·로그 버튼이 65–158px에 모여 머리 주변과 경쟁한다. 장 제목은 짧게, 영문 부제는 진입 시만 표시하거나 숨겨도 된다.
- **기술 용어:** 설정의 “서버 환경변수 사용”, 하단의 “서버 연결 모드”는 일반 플레이어에게 구현 용어다. 상태는 “AI 대화 연결됨” 정도로, 세부 연결 정보는 별도 도움말로 옮길 수 있다.
