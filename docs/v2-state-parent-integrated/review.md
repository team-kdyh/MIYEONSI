# 현재 로컬 통합본 — 실제 대화 재검증 대기

2026-11-21. 선택지 없는 대화·전체 화면 연출·12개 그림 포즈/인물·8개 음악을 유지하면서 약속의 공동·부분 이행을 조건별로 저장하도록 보완했다. 이 문서는 출시 승인이나 모든 자연어 이해의 보증이 아니다.

## 변경과 검토

Ralph 상태 개선 G1의 조건/수행자/대상/원 약속/수락/근거 ID와 저장 구조를 반영했다. 여기에 독립 재현으로 확인한 원래 행동 조건 누락, 명사 조각을 이행 조건으로 허용, 잘못된 수령인, 무관한 거절에 의한 위임 차단, 같은 턴의 수락과 실제 이행 거절을 수정했다. G2의 거절 후 위임 방지, 상태 기록 상한, 중복 수행에 따른 이력 증가 방지도 합쳤다. 명시적 위임은 원 수행자와 변경 근거를 남긴다. 구버전 근거가 없으면 완료를 새로 만들어 내지 않는다.

약속 기록 형식을 설명하는 제공자 지침을 보완했으며 캐릭터 대사와 사용자 입력은 자유 문장으로 유지한다. 실제 동의·수행·이동·연인·데이트·결말의 서버 검증과 오류 시 원자적 저장 취소도 유지한다. Windows 실행기는 파일 해시를 .NET으로 계산하고 배치 종료 코드를 보존한다.

`artifacts/docs/v2-parent-integration-run/`은 354개/25개 검사 시점의 고정 기록이다. 초기 전체 검사에서351개가 통과하고 과거 JSON fixture3개 누락으로 실패한 로그도 보존했다. 정확한 원본 fixture를 복사한 후354개가 통과했다. 이후 G2 수정과4개 검사를 더한358개 결과는 `final-run/v2-parent-final-boundary-run/`에 별도 최종 실행 기록으로 남겼다. 이 과거 응답 재생은 새 모델 호출이 아니다.

`candidate.json`은 직전 통합 시점, `integration-final.json`은 마지막 G2 변경 시점의 구성요소 해시다. 최종 핵심 해시는 commitments `d29ef52d…`, narrative `80dc19e6…`, provider `1019c72d…`, storage `dc866ea9…`다. 테스트한 격리 사본과 원본 파일을 바이트 단위로 비교해 반영했으며 과거 보고서와 개인 저장은 보존했다.

## 남은 한계

약속 검증은 제한된 한국어 문장 구조와 근거 확인을 사용한다. 조사 없는 AI의 원 약속 기록은 보수적으로 거절될 수 있으며, 목적어 앞 색상·시간·수량 조건과 모든 표현의 의미를 일반적으로 증명하지 않는다. 사용자 이행 발화의 일반적인 조사 생략은 유지했다. 바뀐 스키마와 지침을 실제 모델이 안정적으로 따르는지는 아직 관찰하지 못했다.

최신 후보의10턴 이상 연속 실제 대화, 같은 저장의 양 모드 분기와 후속 서사 영향, 전체 로맨스/후반 결말 경험 검증이 남는다. 기존 실응답은 해당 소스 해시의 역사적 증거로만 유지한다. [추가 검증안](../v2-final-live-plan-state-pending.md)은 실제 승인을 대신하지 않는다. 원래 Ralph 판정은 수정하지 않으며 별도 통합 검사도 그 판정을 PASS로 바꾸지 않는다.

최종 정확한 소스·런타임 비교는 [final-candidate.json](final-candidate.json)에 있다. 초기 대조에서15개 파일에 CRLF/LF 차이를 발견해 [기록](line-ending-normalization.json)했고, 의미상 내용이 같은지 확인한 뒤 검사한 바이트로 맞췄다. 컴파일된 dist는 처음부터 동일했다. 최종 server/src/public/dist 전체가 검사한 사본과 바이트까지 동일하다. 추가 의미 변경이나 유료 호출은 없다.

최종 긴 대화 캡처4장을 실제 열어 확인한 범위는 [직접 화면 관찰](direct-visual.json)에 기록했다. 얼굴·입력창은 보이며 스크롤 위치에서 첫 줄 일부가 잘리고 하단 안내가 페이드와 겹친다. 모바일 보조 글씨와 모든 포즈의 손 가시성을 과장하지 않았다.

실제 상태 개선 Ralph는2세대 후 `grade_regressing`으로 종료됐다. 공식0/7, QA0.52/REVISE 원문은 [종료 기록](../v2-state-ralph/terminal.json)에 보존했다. 평가 대상 작업자의337개 테스트와 부모 추가 통합본의358개는 서로 다른 범위다. 일반적인 약속 내용 변경·버전 관리, 최신 실대화 및 직접 평가 증거의 부족이 남았으며 이 보고서로 공식 판정을 변경하지 않는다.
